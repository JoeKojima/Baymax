Microphone input

Waiting for audio telemetry.

Record a microphone test and play it back. While Ember is running, the test taps the active Gemini-bound input stream instead of opening the microphone again. The replay uses the browser's audio output; use the speaker test below to check Ember's selected speaker.

If raw input rises but cleaned input stays silent, check reply muting, echo protection and cleanup status. If both rise but no user transcript appears, the issue is farther along the send or speech-detection path. These are sound levels, not speaker identity.
