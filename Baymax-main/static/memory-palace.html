How to read this palace

A person can share a memory with other people. These are views of one memory store, so the same shared event is not copied into separate databases.

“In initial prompt” means the runtime placed this memory into its system instruction. “Recalled this session” means it sent the entry during the conversation. Neither proves the model used it in a particular reply, and a compressed session may no longer retain recalled text.

People links currently use names. A face in view is not a verified speaker. Older memories without person links stay in Unattributed; the inspector does not guess who owns them. Memory summaries can be wrong.

Memories persist in this Ember's data folder. API keys authenticate Gemini; they do not identify a person or create memory spaces. Closing this window or restarting Ember does not clear saved memory. Separate data folders create separate spaces. The profile selector scopes future memories; saved entries remain read-only here.

Snapshots refresh every five seconds while v10 debugging is enabled. Up to 500 entries are shown; larger stores can be incomplete. The active tree shows up to 100 evidence-linked proposals grouped by category. Supplied profile IDs enable scoped graph recall. Person identification is handled by other features. Relationship inference, automatic conflict resolution and feed ranking remain future work.
